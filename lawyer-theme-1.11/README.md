# Lehoia - Professional Lawyer WordPress Theme

A modern, professional WordPress theme designed specifically for lawyers, law firms, and legal professionals.

## Features

- **Responsive Design**: Fully responsive and mobile-friendly
- **Professional Layout**: Clean, modern design with dark navy background and gold accents
- **Custom Post Types**: Practice Areas, Case Results, and Testimonials
- **Customizer Options**: Easy customization through WordPress Customizer
- **SEO Optimized**: Built with SEO best practices
- **Fast Loading**: Optimized for speed and performance
- **Contact Forms**: Built-in contact form functionality
- **Google Fonts**: Beautiful typography with Playfair Display and Inter fonts

## Installation

1. Download the theme package
2. In your WordPress admin, go to Appearance > Themes
3. Click "Add New" then "Upload Theme"
4. Upload the lehoia.zip file
5. Activate the theme

## Setup

### Required Images
Place these images in the `/assets/` folder:
- `lawyer-hero.jpg` - Hero section lawyer photo
- `lawyer-about.jpg` - About section photo
- `awards-badges.jpg` - Awards/badges image
- `testimonial-client.jpg` - Client testimonial photo

### Customization
1. Go to Appearance > Customize
2. Configure Site Identity settings
3. Set up Contact Information
4. Upload your custom logo
5. Customize colors and typography as needed

### Content Setup
1. Create pages for different sections
2. Add Practice Areas using the custom post type
3. Add Case Results to showcase your wins
4. Add client Testimonials
5. Configure contact information
